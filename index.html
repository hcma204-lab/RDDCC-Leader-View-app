設定

資料來源：monday
怎麼取得 token？
  1. 在 monday 點右上角頭像 → Developers。
  2. 選 My access tokens，在 API token 旁按 Show，再按複製。
  3. 貼到上面的欄位。不要貼給任何人：它等同你的 monday 帳號權限。
  4. 找不到 Developers：管理員尚未開放，請他允許你保留這個功能。
AI 端點（選填；不設定也能用所有本機分析）
綁定我的 Claude 帳號（不需要 API key，用公司 Claude 帳號）
尚未偵測
你正在使用本機版：AI 會自動綁定你自己的 Claude 帳號；第一次需要登入公司帳號（只需一次）。
還沒安裝？要用 AI 才需要（約 5 分鐘）
在公開網址上，瀏覽器通常不讓網頁連到你電腦上的程式，所以要用「本機版」。不用 AI 的人不需要做這些，所有分析都能正常使用。
  1. 下載安裝包：下載 ZIP，解壓縮到固定資料夾（例如 D:\ClaudeBridge）。
  2. 雙擊裡面的 install-bridge-autostart.bat（只需一次）。需要已安裝 Node.js 18 以上，以及 Claude 桌面 App 或 Claude Code。若 Windows 跳出藍色警告，按「其他資訊」→「仍要執行」。
  3. 開啟 http://127.0.0.1:8787/（本機版儀表板），到「設定」貼上你自己的 monday token，並按「綁定我的 Claude 帳號」。第一次會請你用公司 Claude 帳號登入。
  4. 每個人用自己的電腦與自己的 Claude 帳號，互不影響；之後開機會自動啟動，直接開上面的網址即可。
進階：改用 API key 或其他 AI 端點（一般不用）

行為

資料與 AI 使用說明（治理）

唯讀只讀取 monday，不修改看板內容
人工把關AI 只給建議與草稿，不自動發送
資料在自己電腦token、紀錄只存本機，不上傳

讀什麼、寫什麼

  • 用每個人自己的 monday 個人 token讀取「研發文管課-工作進度追蹤」；你只看得到自己有權限的看板。
  • 儀表板本身沒有任何寫入 monday 的功能。
  • 唯一會寫入的是每日排程：把晨報、預警寫到一個私人的「輸出看板」，不改動來源看板。

AI 會看到什麼

  • 晨報、問答、總經理摘要：只收到彙整後的欄位（項目名稱、負責人、狀態、日期、逾期／無動靜天數）。
  • 週會摘要：另含各項目「重點事項」文字（每項最多 500 字）。
  • AI 預審：只有你按下按鈕的那一個項目，會送出它的內容描述、重點事項、檔名、子項目與最近留言。
  • AI 透過你自己的公司 Claude 帳號回答，不使用 API key；橋接程式只接受本機連線，執行時不開放任何工具、不保留對話，也不記錄提問與回覆內容。

資料放在哪

  • monday token、設定、成效紀錄都只存在這台電腦的瀏覽器，不在程式碼、網址或 GitHub 上。
  • 可隨時按「登出」清除 token，或在「成效」頁匯出、清除紀錄。

誰負責、怎麼把關

  • 催辦訊息只是草稿，由主管檢視後自行發送。
  • AI 內容僅供參考，看板無法判斷的事（例如項目是否已線下審過）一律標示「待確認」。
  • 「可能逾期」是規則推估，每項都列出理由，並在「成效」頁追蹤預警後的實際結果。

已知限制

  • 每日排程需要電腦開機且 Claude 桌面 App 開著；沒執行的日子就沒有晨報。
  • 主管審核天數以「完成日期」到「主管審核日期」計算；若同仁晚填完成日期，數字會偏短。
  • 目前為試辦版，由個人 GitHub 頁面提供；擴大使用前應移到公司指定的位置。
