怎麼取得 token？
  1. 在 monday 點右上角頭像 → Developers。
  2. 選 My access tokens，在 API token 旁按 Show，再按複製。
  3. 貼到上面的欄位。不要貼給任何人：它等同你的 monday 帳號權限。
  4. 找不到 Developers：管理員尚未開放，請他允許你保留這個功能。

尚未偵測
你正在使用本機版：AI 會自動綁定你自己的 Claude 帳號；第一次需要登入公司帳號（只需一次）。
要用 AI 的人，請用「本機版」（在公開網址上，瀏覽器通常不讓網頁連到你電腦上的程式；不用 AI 的人不需要做這些，所有分析都能正常使用）：
  1. 下載安裝包：下載 ZIP，解壓縮到固定資料夾（例如 D:\ClaudeBridge）。
  2. 雙擊裡面的 install-bridge-autostart.bat（只需一次）。需要已安裝 Node.js 18 以上，以及 Claude 桌面 App 或 Claude Code。若 Windows 跳出藍色警告，按「其他資訊」→「仍要執行」。
  3. 開啟 http://127.0.0.1:8787/（本機版儀表板），到「設定」貼上你自己的 monday token，並按「綁定我的 Claude 帳號」。第一次會請你用公司 Claude 帳號登入。
  4. 每個人用自己的電腦與自己的 Claude 帳號，互不影響；之後開機會自動啟動，直接開上面的網址即可。
啟用 AI 時，被你按下按鈕的那一次，會把「彙整後的項目名稱、負責人、日期、狀態」送到上面的端點。請只使用公司核准的端點。
